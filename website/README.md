# RelateKit documentation site

Run the local site with `npm run docs:start` from the repository root. The command builds RelateKit and checks the website types before starting Docusaurus. Build static files with `npm run docs:build`. Docusaurus writes the site to `website/build`.

The site uses Docusaurus 3 and requires Node.js 20 or newer. The RelateKit package itself supports Node.js 18 or newer.
